It reads the reviews so you don't have to

For every title, an AI reads what critics actually wrote about the fights. It pulls out the lines that matter and turns them into five scores. Code does the ranking, so the order never drifts with a mood.

      Fists and blades come first

      Every title earns a base score from its fights. Then the style it fights in decides how much of that score it keeps. This is the rule the code runs, straight from its weights file.

      1. Hand-to-hand, swordplay and wuxiakeeps the full score
      2. Mixed styleskeeps 90 percent
      3. Gun-fukeeps 85 percent
      4. Brawlingkeeps 80 percent
      5. Action that is not built on fightingkeeps half

      So a great gunfight film can still top the shelf. It just has to fight harder to get there.

        Everything on TMDB, not just the shelf

        The shelf is the part that has been scored from reviews. Each mode holds a ranked list of titles. Ask the chat about anything else and it looks the title up on TMDB live, 2026 releases included.

        When nobody has read the reviews for a title yet, it says so. You get the facts from TMDB and a plain flag instead of a made-up score.
